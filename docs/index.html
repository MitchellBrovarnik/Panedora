About Panedora

About the project.

Panedora is an independent project by Mitchell Brovarnik. It brings Pandora station listening into a desktop app, with themes, lyrics, mini-players, and optional Discord sharing.

The source is available on GitHub, along with release notes, discussions, and a place to report issues or suggest improvements.

Visit the project ↗

Privacy

No analytics.
No ad trackers.

Your login stays between you and Pandora

The app signs in directly with Pandora. Panedora does not run a separate server that receives your credentials.

Saved credentials are encrypted locally using your operating system’s secure storage when available, with an app encryption fallback. Authentication data is cleared when you sign out.

The services the app talks to

Lyrics use LRCLIB, which receives the song title and artist. Update checks and this website’s download links use GitHub. Those services receive network information such as your IP address, but not your Pandora credentials.

If you enable Discord sharing, listening details and the artwork URL go to your local Discord client for display on your profile. Pandora credentials, session tokens, and audio URLs are never included.

Windows installation note

SmartScreen may show “Windows protected your PC” because the app does not have a code signing certificate. If you have downloaded Panedora from this project and choose to install it, select “More info,” then “Run anyway.” The source is available on GitHub.

macOS installation note

If macOS says “Panedora is damaged and can’t be opened,” open Terminal and run xattr -cr ~/Downloads/YOUR_FILE.dmg, replacing YOUR_FILE.dmg with the downloaded file’s name, then reopen the .dmg.

If you see “unidentified developer,” right-click the app, choose “Open,” then “Open” again.
